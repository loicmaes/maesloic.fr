# Condiciones generales de venta

## 1. Servicios

Studio Klypi ofrece servicios personalizados de desarrollo web y creación digital.

## 2. Precios

Los servicios se presupuestan individualmente. Los precios están indicados en euros, sin impuestos (HT).

## 3. Pedidos y pago

El pedido se confirma tras la aceptación escrita del presupuesto. Puede solicitarse un anticipo. Las modalidades de pago se acuerdan (por transferencia bancaria, etc.).

## 4. Plazos de entrega

Los plazos son estimativos. Studio Klypi informará al cliente en caso de retraso.

## 5. Derecho de desistimiento

De conformidad con el artículo L221-28 del Código del Consumo francés, no se aplica el derecho de desistimiento para servicios personalizados ya iniciados con el consentimiento del cliente.

## 6. Responsabilidad

Studio Klypi no se hace responsable de los daños indirectos derivados del uso de los entregables.

## 7. Litigios

En caso de litigio, se buscará una solución amistosa. De no ser posible, se acudirá a los tribunales competentes de Estrasburgo.

*Esta traducción se proporciona únicamente con fines informativos. En caso de conflicto, prevalecerá la versión original en francés.*
