# 💼 [maesloic.fr](https://www.maesloic.fr) - Digital Resume

Welcome to my personal website — a digital version of my resume showcasing my professional journey, technical skills, and personal projects in a clean and modern format.

## 🚀 About

This project was built to:
- Centralize and highlight my professional profile
- Present my experience, skills, and projects in a structured way
- Serve as an interactive support for recruiters and collaborators
